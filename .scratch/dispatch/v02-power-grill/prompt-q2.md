## 已定的上位决策（Q1，勿推翻，只在此基础上答 Q2）

- **A 为主**：测**法庭 ROC**——注入一个强度 s 的真信号，**强制它当被判决候选**（条件在
  "已选中"），仍嵌在 99 噪声池里让池关（FDR/PBO/pool-max）真实运作；报 P(法庭放行 |
  强度 s)。旁记它的自然 max|t| 胜出率当派生备注 B。size 用现成 killer-demo 校准位同轴对照。

## 技术约束（我核过）

- null 壳：纯 RNG AR(1) 因子面板，**与收益数据统计独立**，对**真实 csi300 forward
  return**（label `Ref($close,-2)/Ref($close,-1)-1`）算 RankIC ≈ 0。
- 零假设下日度 RankIC 序列**无自相关**（IC_t 噪声来自每日新鲜、非重叠的 forward return）。
- 评价路径 = adapter.evaluate（RankIC）/ evaluate_shifted，court 内核只吃收益/IC 序列。

## Q2：注入已知强度真信号，用哪个机制？

- **(b) 保留真收益，因子掺未来收益信息**：`factor_i,t = β·rank(forward_return_i,t) +
  √(1−β²)·AR(1)噪声`。强度旋钮 = β；评价台一字不变（真收益、同 adapter/窗口/宇宙/种子
  树）。power 与 size **只差注入的 mean-IC**，其余结构（含 IC 序列无自相关 → iid-t 仍
  校准）全同。代价：信号是"每天偷看当日未来收益"= **构造性 look-ahead**（故意的标定
  机制，诚实边界已声明"构造≠真 alpha"），且信号每天新鲜、非持久。
- **(a) 合成收益 + 潜因子驱动**：造持久潜信号同时驱动因子分与未来收益
  （`ret=γ·latent+市场噪声`, `factor=latent+测量噪声`）。信号结构更像真 alpha（持久），
  但**抛弃真收益、引入第二个要另行指定并辩护的收益模型**（γ、市场噪声、潜因子持久度…）。

指挥官的**倾向是 (b)**，理由：① null 壳的对称镜像，power/size 只差一个均值 → 归因无污染；
② 保 iid-t 校准（非重叠收益 → IC 无自相关）；③ 少一个自由度（(a) 要另拍一整套合成收益
模型）。
