# alpha-court 使用指南

README 是门面，这里是说明书：法庭吃什么、判什么、每个统计量怎么调用、
判决怎么读。所有代码片段的函数签名与仓库实现逐一核对过。

## 0. 定位：它不做回测

alpha-court 的输入是**你的回测框架已经产出的东西**——一条（或一批）收益
序列 / IC 序列，外加一个诚实的"我一共试了多少次"。它输出的是判决：
这个结果在选择效应校正之后，还该不该信。

四把刀，各答一个问题：

| 统计量 | 回答的问题 | 文献 |
|---|---|---|
| DSR 缩水夏普 | 这个"最好成绩"比纯噪声试 N 次的期望冠军好吗 | Bailey & López de Prado 2014 |
| PBO（CSCV） | "样本内挑最优"这个动作本身的过拟合概率多大 | Bailey, Borwein, López de Prado & Zhu 2017 |
| BHY-FDR | 一族检验里按什么门槛拒绝才控制得住错误发现率 | Benjamini & Yekutieli 2001; HLZ 2016 |
| 经验噪声对照 | 跟信息为零的对照组比，它排第几（个体关+池最大关） | Phipson & Smyth 2010; White 2000 |

## 1. 安装

```bash
pip install -e .          # 核心只依赖 numpy/pandas/scipy (Python ≥ 3.10)
pip install -e ".[demo]"  # 跑 killer demo 需要 matplotlib
pip install -e ".[dev]"   # pytest / ruff
python -m pytest -q       # 全部测试应通过
```

铁律：`court/` 是市场无关内核，永不 import 任何市场代码；市场特异性
（数据适配）全部关在 `adapters/`。

## 2. 先看杀手 demo

```bash
python -m examples.killer_demo    # 预注册主种子, 干净 checkout 上确定性复现
```

它做的事：造 100 个构造上就是纯噪声的因子 → 让"天真研究员"按全窗口 |t|
最大挑出"最强因子" → 全部 100 个交给法庭过五关电池 → 判决书落在
`examples/killer_demo/out/report.md`。

判决书四个部分怎么读：
- **头版**：幸存者计数（0/100）与被选中标本的全部读数；
- **停尸房表**：100 个被告逐个的五关判决矩阵；
- **标本解剖**：对"最强因子"的逐关拆解——它过了自己的个体噪声关
  （p̂=0.015），死在池最大关（p̂=0.575）。同一个数字，放回"百里挑一"
  的语境立刻现形，这就是被校正的选择效应；
- **校准附录**：电池在已知答案（纯噪声）上的行为校准。

## 3. 把你自己的回测结果带上法庭

以下是最小可用路径：四把刀都是纯函数，直接喂数组。

**频率纪律（最容易翻车，先说）**：所有 Sharpe 与序列必须是**同频原生值**
——日收益就传日频 Sharpe（mean/std，不年化），把年化 Sharpe 传进任何
公式都是错的。峰度一律**原始峰度**（正态=3；pandas `.kurt()` 是超额
峰度要 +3）。

### 3.1 DSR：我的最好成绩缩水后还显著吗

```python
import numpy as np
from court import series_moments, dsr

r = np.asarray(daily_returns)            # 你的策略日收益(超额), 1-D
m = series_moments(r)                    # n_obs / SR̂ / 偏度 / 原始峰度

result = dsr(
    sr_hat=m.sr_hat,                     # 日频 SR, 不年化
    n_obs=m.n_obs,
    skew_hat=m.skew_hat,
    kurt_hat=m.kurt_hat,
    sr_trials_std=0.02,                  # 全部 N 次试验 Sharpe 的截面 std
    n_trials=60,                         # 诚实的试验计数(见 3.5)
)
# result.dsr     > 0.95 才过 95% 置信
# result.sr_star 是"纯噪声试 N 次的期望冠军成绩"——你的对手不是 0
```

试验彼此相关时，用 `avg_pairwise_correlation`（T×M 试验收益矩阵）+
`implied_independent_trials` 把名义 M 折算成有效独立 N̂ 再传入。

### 3.2 PBO：样本内选最优这个动作有多容易过拟合

```python
from court import pbo_cscv, sharpe_ratio

# values: T×N 矩阵, N 个候选配置的同频收益, 行按时间排列
res = pbo_cscv(values, n_splits=16, metric=sharpe_ratio)
# res.phi: IS 冠军在 OOS 掉进下半区的频率。纯噪声≈0.5, 真技能→0, 系统性过拟合→1
```

### 3.3 BHY-FDR：一族因子检验按什么线拒绝

```python
from court import fdr_by

res = fdr_by(p_values, q=0.05)   # 任意相依结构下有效(harmonic 修正)
# res.k_star 个入选; res.adjusted_p 与 R p.adjust("BY") 逐位一致
```

### 3.4 经验噪声对照：跟零信息对照组比排第几

```python
from court import empirical_null_p

# 个体关: nulls = 该因子自己的信息破坏版(如循环时移)统计量抽样
# 池最大关: observed = 你"选出来"的最强统计量,
#           nulls   = 每个噪声池各自的 best-of 统计量(White 2000 语义)
res = empirical_null_p(observed, nulls, alpha=0.05)
# 加一估计, p̂ 永不为 0; 平手计入对候选不利的一侧
```

**两关语义务必分清**：个体关只回答"它比自己的噪声版强吗"；只有池最大关
校正"我是从一堆里挑出来的"这个选择效应。killer demo 的标本恰好演示了
只过前者、死于后者。

### 3.5 N 从哪里来（法庭的输入端诚信）

DSR 的杀伤力取决于 N 的诚实。经验规则：调过的每组参数、废掉的每个草稿
都算一次试验。低报 N = 给自己伪造判决。完整流程（下一节）用 append-only
台账把 N 变成可对账的记录，而不是记忆里的数字。

## 4. 完整法庭流程（ledger + judge）

纯函数之上还有一层可选的"程序正义"：

```
Ledger(append-only 台账)
  ├─ HypothesisRecord   一个经济主张(如"动量预测收益")
  ├─ TrialRecord        一次评估 = 一个配置×一个窗口 → 一条收益序列
  │    └─ DeclaredProtocol  注册时冻结的评估协议(指标/方向/窗口/频率)
  └─ VerdictRecord      judge 对明确 scope 的一次判决, 只追加不改写
```

- **预注册**：协议在收益序列存在之前锁进 TrialRecord——先定判据后看结果；
- **judge**（`court.judge`）：读台账证据，在每个 trial 的已声明协议下算
  统计量，逐条落 VerdictRecord；不跨统计量聚合——电池怎么组合、幸存
  标准是什么，属于研究设计（参考 `examples/killer_demo/battery.py`）；
- trial 计数从台账直读，对账由 `harness/` 的门负责（计数对账、
  anti-pattern lint、CONFIRM 预算门）。

词汇表见 `CONTEXT.md`，逐统计量的规格与裁定记录见 `docs/design/` 与
`docs/research/`（每个实现决定都能回溯到一条编号裁定）。

## 5. 判决怎么读（速查）

| 读数 | 通过线 | 注意 |
|---|---|---|
| `dsr` | > 0.95（95% 置信） | 必须连 N 一起报；`sr_star` 是对手成绩 |
| `phi`（PBO） | 越低越好；≈0.5 即纯噪声 | 对 N 个候选整体成立，不是对单个 |
| `k_star`（BHY） | 入选个数；0 = 全族无发现 | 拒绝的是"整段前 k* 名"，含压线者 |
| `p_hat`（噪声） | ≤ α 过关 | 个体关过 ≠ 池最大关过，语境不同 |

单关通过不等于活着——killer demo 里被告过了个体关照样 0/100。电池的
裁决权在设计者手里，法庭只保证每关的数字算得对、留了痕。

## 6. 扩展点

- `adapters/`：接自己的数据源/市场（现有 qlib-cn CSI300 PIT 适配器）；
- `examples/killer_demo/`：电池组合与判决书渲染的参考实现，改造它即可
  搭自己的验证流水线；
- `harness/`：研究过程之门（trial 对账、反模式 lint、发布审计），
  与统计内核解耦，可单独取用。
