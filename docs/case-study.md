# alpha-court —— 它是怎么造出来的

*一个会驳回假 alpha 的因子验证工具——以及一套刻意设计成"让作者自己也骗不了自己"的
建造流程。下面每个数字都现读自本文所在 commit 的仓库，不引记忆。*

---

## 1. 打头的这个 demo

我生成了 **100 个构造上就是纯噪声的因子**——零信息是设计出来的、不是碰巧的持久随机面板。
然后放一个"天真研究员"进去：挑全窗口 |t| 统计量最大的那个，宣布"发现"了。天真选择果然
"挑出"了一个：

> **`volatility_lb150_v14`** —— 方向 contrarian，**|t| = 2.6655**，裸 **p = 0.0077**，
> 年化 ICIR = −1.93。单看它像真的，裸 p 值过了 0.01。

然后把 100 个全交给 `alpha-court`。判决书头版：

> **幸存者：0 / 100。**

真正长见识的是被告*怎么*死的。它跑了一套五关电池：

| 关卡 | 算了什么 | 判决 |
|---|---|---|
| FDR（Benjamini–Hochberg–Yekutieli） | p = 0.0077 vs q = 0.05 | **驳回** |
| Deflated Sharpe（Bailey & López de Prado） | 被选 Sharpe 为负 → 单侧检验直接驳† | **驳回** |
| PBO / CSCV | φ = 0.47（回测过拟合概率） | **驳回** |
| 经验零分布 · **个体** | p̂ = 0.015 对它自己的噪声抽样 | **通过** |
| 经验零分布 · **池最大** | p̂ = 0.575 —— 199 个噪声因子里 114 个的 best-of 比它强 | **驳回** |

看最后两行。拿它**跟自己的噪声分布**比，被告*过关*——p̂ = 0.015，真像个 1/67 的稀有事件。
拿它**跟它被选出来的那个池**比，它*死了*——199 个纯噪声因子里有 114 个产生了更强的
best-of-window 统计量。同一个数字，两种语境。单独看像信号；放回它真正被"百里挑一"挑出来的
语境，它就是噪声的*中位数*。

† DSR 这一行诚实但在这里是"过度决定"的：DSR *确实*会为搜过的 ~100 次试验做缩水，但这个被告
是个翻了号、Sharpe 为负的因子，所以单侧检验靠符号就驳了它——哪怕只搜 1 次也会驳。杀死*这一个*
的不是多重检验缩水（`report.md` 脚注，killer-demo.md §5.4）；真正校正选择效应的是下面那关池最大。

裸 p 与选择校正后 p̂ 之间的这道缝，就是 alpha-court 存在要诊断的全部病灶，落在一个被告身上。

*（gross 纸面序列：RankIC，CSI300 point-in-time 宇宙，T = 480 个评估日，主种子 20260710，
无交易成本——§5 老实交代这句话到底意味着什么。）*

## 2. 它是什么，为什么

回测框架告诉你*一个 idea 看起来多好*。**alpha-court 告诉你该不该信它。** 它刻意做得很窄：

- **不是回测系统。** 它复用现成引擎（qlib），只吃出来的收益 / IC 序列，从不自己重算 PnL。
- **不是 idea 生成器。** 生成端刻意不在范围内；上面那 100 个噪声因子是*测试夹具*，不是策略。
- **是个验证器。** 给它一个候选 + 产生它的那次搜索，它只诚实回答一个问题：这东西经得起样本外
  吗，还是个选择假象？

这条设计原则在本项目里有名字——**禁赢学**，"不做赢学（winning studies）的纪律"：null 结果与
幸存者同等归档；绝不换个更顺的种子重跑；结果在被证明之前一律当作过拟合。

## 3. 里面装了什么

**一个与市场无关的内核，市场特异性全部隔离。** `court/` 装统计、不得 import 任何市场特异代码；
日历与宇宙定义全部关在 `adapters/` 后面。内核对纯合成面板做测试；适配器才处理 CSI300 现实
（point-in-time 成分），并且公开维护一份 v0.1 的 *declared-not-modeled（声明未建模）* 清单
（涨跌停可交易性、执行时停牌）。这层解耦就是"工具"和"一次性脚本"的区别。

**每个统计量都从公开文献重写、逐条引用：**

- **Deflated Sharpe Ratio** —— Bailey & López de Prado（2014）。
- **回测过拟合概率 via CSCV** —— Bailey, Borwein, López de Prado, Zhu。
- **多重检验校正** —— Benjamini–Hochberg–Yekutieli。

没有任何代码、数据或方法搬自任何前雇主；推导都在 `docs/research/`，公式与实现逐项对得上。

**预注册是一次 commit，不是一句承诺。** 杀手 demo 的设计文档（`docs/design/killer-demo.md`）
——它钉死了种子、判决阈值、以及一驳即死的聚合规则——commit 于 **2026-07-10 23:47**。产出这些
数字的 demo 代码首次出现在 **2026-07-11 04:46**，晚了大约**五个小时**。判决线在结果存在之前就
冻结了——这在 `git log` 里可查；这就是工具把自己的诚实规则反过来用在自己身上。

诚实附注：预注册协议里还写了一个 20 种子稳健性 sweep 附录（killer-demo.md §7.4，种子
20260711–20260730）；主跑发货时它*没跑*——`report.md` 明写 "Sweep not run"、仓库里没有
`out/sweep/`。所以我只主张主跑的种子 / 阈值 / 聚合在结果之前冻结，**不主张整套预注册协议已闭环**
——那个 sweep 附录仍是未执行的诚实债。

## 4. 怎么造的——同一套纪律，反过来对准过程

demo 是产品。本项目的第二个主张是：造它的*方式*同样拒绝让我骗自己。**三个角色，而评估者永远不在
工人的环里：** 一个*指挥官*（Claude Code）设计并裁决、但从不给自己的代码打分；一个*无头工人*
（grok）在隔离 worktree 里实现一张冻结的票；一个*对抗裁判*在任何东西被接收前独立复跑交付物。

v0.1 期间它关掉了 20 张 issue（其中约 14 张派给无头工人，其余是指挥官自撰的设计 / spec / 验收
票），含 8 轮返工、144 个测试函数。吞吐数不是重点、也很容易变成门面数字——要紧的是它抓到的错。
四个，每个都锚在仓库里的一件物证上：

1. **工人赢了。** 造多重检验那一关时，工人指出 **Harvey–Liu–Zhu（2016）§3.4.3 印出来的那版
   BY 递归自相矛盾**——它的初值违反了该方法本该保证的"adjusted-p ≤ q ⟺ reject"恒等式。工人的
   形式是唯一自洽的那个；我判工人胜、驳已发表的论文。勘误记在 `docs/research/bhy.md:285`，代码零
   改动。这是工人第一次赢下对指挥官的裁定；把评估者放在工人环之外，就是为了让这种事有可能发生。

2. **面板抓住了我本会发出去的 blocker。** 适配器交付从对抗审回来时带着 *1 个 BLOCKER、2 个
   major、4 个 minor*（`.scratch/dispatch/v0.1-10a-adapter-impl/rework-01.md`）；那个 blocker 是
   秩-在-联合掩码-内 的缺陷，本会悄悄污染 demo 的 IC——在它抵达报告前就被抓住。

3. **角色反转外审给我打了 B。** v0.1 里程碑上，我让一个 fresh 的跨模型评审去给*指挥官*打分。它的
   一句话结论是"配做指挥官，还不配对自己同样严苛"——设计 A−、工程卫生 C+、裁判公正 B−，三条批评
   是事后立法、派单桥自伤、验收尺度不一（`.scratch/dispatch/meta-review-commander/`）。我把这三条写进了
   两个技能的文本（`worker-dispatch`、`adversarial-referee`）；但得老实说：那条"对工人严、对自己松"的
   双重标准，外审说的正是它、至今没消——把一个 B 收成纪律勋章，本身就是又犯了同一个毛病。

4. **回路需要一个人来触发，而我一再造假牙。** 那个把抓到的教训转成规则的自成长"反流"回路，触发了
   四次；第四次是一个*人*、不是机器，去触发的它——自动化没抓到自己的失职。而设计文档记着我一条
   反复犯的毛病——**CR-08**：我建一道"门"、只测 happy path、就管它叫牙（reflow-gate、prereg-gate 都
   栽过）。所以进了 `main` 的那道门（`scripts/skill-review-gate.sh`，它机械化的其实是 **CR-07**：skill
   无外审不得 merge），我特意按 CR-08 的规矩*先写了绕过红测*——它会在我当初"skill 无外审就 merge"的
   真实 commit 区间上 FAIL。但 CR-08 真正那颗牙（把预注册内容 hash 进 run config、判决时比对）仍是
   [已设计、未建]。

## 5. 诚实状态——正是这一节证明立论

一篇讲"不骗自己"的案例，必须说清什么*还没*做。状态标签是字面意思。

- **[已落地 LANDED]** 内核、五关电池、CSI300 适配器、端到端杀手 demo、144 个测试函数、确定性复跑。
  一道*手动*评审门（`scripts/skill-review-gate.sh`）——**对着它存在要拦的那条真 sin 做过红测**：它会
  在我当初无外审就 merge skill 的那条真实 git 区间上 *FAIL*。手动、未接入 merge：它查的是评审
  *共同在场*、不是实质。
- **[已设计、未建 DESIGNED]** 真正的强制牙：把预注册的种子 / 阈值 / 聚合 hash 进 run config、在判决时
  比对，让一项研究*不可能*在看到结果之后被悄悄重调。今天这道门只查 commit *顺序*，弱得多。
- **[已推迟 DEFERRED]** 这个 demo 是 gross 纸面序列、无交易成本 / 无容量模型——所以"净额（net-of-cost）"
  的话目前都只能算愿望、要等 v0.2 成本模型。一个生产因子台需要的桌面肌肉（带停止规则的多重检验
  预算、IC 半衰期与滚动 OOS、regime 依赖、拥挤度、实现损耗、容量屏）都被点名为"尚未建"，所以不会
  被静默声称已做。

还有最锋利的一句自认，因为它恰恰就是本项目要治的病：**我不止一次建一道"门"、只测 happy path——从不
测绕过——然后就管它叫牙**（设计文档把它记作一条常驻失败模式，CR-08）。现在的规则是*先写绕过红测*，
因为把"我怎么骗自己"点破，是唯一真拦得住它的东西。

## 6. 这想说明什么

两件事，我把物证指给你，不替它们下结论：

- **一个量化验证工具**：100 个纯噪声因子 → 裸选择"发现"一个假 alpha → 法庭 0/100，被告死在池最大关
  （p̂ = 0.575）。这段（§1）逐项对得上 `report.md`。
- **一套本仓库真用过的施工痕迹**：跨模型对抗审查、一个被允许赢的工人、一个对自己缺口诚实、也被外审
  打过 B 的自纠错回路——不是一件打磨好的产品，是留了痕的过程。

可迁移的部分不是 CSI300 的接线，而是判断力：**看之前先预注册，让评估者坐在环外，把你抓到的错写下来
——尤其是你自己的错。**
